## ✨ 版本信息
- **适用系统**：Windows 10 / Windows 11 (64位)

## 🚀 核心特性
- **免安装 / 绿色化**：双击主程序即可运行，不写入系统注册表，不产生系统垃圾。
- **数据完全独立**：浏览器产生的书签、历史记录、Cookie 和扩展插件都保存在软件根目录的 `Data` 文件夹中，不污染当前电脑原有的 Chrome 浏览器。
- **完美便携**：非常适合存放在 U 盘、移动硬盘中，换电脑即插即用，保留你的所有上网习惯。
- **纯净无捆绑**：仅基于官方原版打包，未添加任何主页锁定或第三方流氓软件。

## 📥 下载与使用
1. 前往右侧（或下方）的 **[Releases](../../releases)** 页面，下载最新版本的压缩包（`.zip` 或 `.7z`）。
2. 使用解压软件（如 7-Zip、Bandizip）将压缩包 **完整解压** 到本地文件夹或 U 盘。
   > ⚠️ **注意**：请务必解压后再使用，**不要**直接在压缩包内双击运行，否则无法保存数据！
3. 进入解压后的文件夹，双击 `Chrome.exe`（或你的主程序命名）即可启动浏览器。

## 💾 数据说明
- **书签与密码**：如果你需要把旧电脑的 Chrome 数据迁移过来，可以将旧电脑的 `User Data` 文件夹覆盖到本便携版的对应数据目录中。
- **清理数据**：如果你想重置这个便携版，只需删除数据文件夹内的内容（或重新解压一次即可），它会恢复为纯净的初始状态。
