# 将便携版（绿色版）浏览器设置为系统默认浏览器

> 记录日期：2026-11-21
> 适用系统：Windows 10 / Windows 11（本文实测环境为 Windows 11 25H2）
> 适用对象：Chrome / Edge 等基于 Chromium 的便携版（免安装、绿色版）浏览器
> 实测对象：Edge 便携版 `D:\MyApp\Browser\Edge\EdgePortable`

---

## 一、背景与核心难点

便携版浏览器的优势是免安装、可整体拷贝、不写系统目录，但这恰恰带来一个问题：**它没有经过系统安装器注册，因此不会出现在 Windows 的"默认应用"候选列表里**，也无法通过常规方式设为默认浏览器。

更关键的是，Windows 10/11 对默认浏览器采用 **UserChoice 哈希保护机制**：

- 默认浏览器记录在两个注册表位置：

  ```
  HKCU\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\http\UserChoice
  HKCU\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\https\UserChoice
  ```

- 这两个键除了 `ProgId`（指向处理程序）外，还有一个由系统计算的 `Hash` 值。
- **任何脚本直接改写 `ProgId` 都会被系统识别为篡改并自动还原**，无法持久生效。

因此，"脚本一键设为默认浏览器"在 Windows 10/11 上是走不通的。可靠的唯一路径是分两阶段：

> **先把便携浏览器注册成系统认可的浏览器应用 → 再由用户在系统设置界面手动点选**（点选时由 Windows 自行计算 Hash，才能持久生效）。

---

## 二、总体思路

| 阶段 | 做什么 | 由谁完成 | 是否写 UserChoice |
|---|---|---|---|
| 阶段一：注册 | 把便携浏览器写入系统的浏览器应用登记（HKCU 四类键） | 脚本 / 工具 | 否 |
| 阶段二：点选 | 在"设置 → 默认应用"里选它 | 用户手动 | 是（由 Windows 计算 Hash） |
| 验证 | 检查 UserChoice 的 ProgId 是否已切换 | 脚本 | 否（只读） |

核心原则：**不碰 UserChoice，只做注册和引导**。

---

## 三、阶段一：注册为系统认可的浏览器

### 3.1 需要写入的四类注册表项

全部写在 `HKCU`（当前用户）下，**无需管理员权限，不影响系统自带浏览器**。

| 类别 | 注册表路径 | 作用 |
|---|---|---|
| ① ProgID | `HKCU\Software\Classes\<ProgID>\shell\open\command` | 定义"打开网页文件/链接"时执行的命令 |
| ② StartMenuInternet | `HKCU\Software\Clients\StartMenuInternet\<AppKey>` | 声明这是一个浏览器客户端 |
| ③ Capabilities | `...\StartMenuInternet\<AppKey>\Capabilities` | 声明能处理的协议、文件类型、MIME |
| ④ RegisteredApplications | `HKCU\Software\RegisteredApplications` | 让应用出现在"默认应用"列表 |

### 3.2 完整注册脚本（可直接执行）

以下为本次实测通过的版本，保存为 `.ps1` 执行即可。修改开头的路径变量即可适配其他便携浏览器。

```powershell
$ErrorActionPreference = 'Stop'

# ===== 按实际情况修改这里 =====
$exe     = "D:\MyApp\Browser\Edge\EdgePortable\App\msedge.exe"   # 便携浏览器主程序
$data    = "D:\MyApp\Browser\Edge\EdgePortable\Data"             # 用户数据目录
$prog    = "EdgePortableHTML"                                     # ProgID（自定义，勿与系统冲突）
$app     = "EdgePortable"                                         # AppKey（自定义）
$display = "Microsoft Edge (Portable)"                            # 显示名

# 打开链接/文件时的命令行（注意 --single-argument %1，保证 URL 正确传入）
$openCmd = '"{0}" --user-data-dir="{1}" --no-first-run --no-default-browser-check --single-argument %1' -f $exe, $data
# 从开始菜单启动时的命令行（无 %1）
$appCmd  = '"{0}" --user-data-dir="{1}" --no-first-run --no-default-browser-check' -f $exe, $data

# ① ProgID：文件类型处理程序
New-Item -Path "HKCU:\Software\Classes\$prog" -Force | Out-Null
Set-ItemProperty "HKCU:\Software\Classes\$prog" -Name "(default)" -Value "$display HTML Document"
New-Item -Path "HKCU:\Software\Classes\$prog\shell\open\command" -Force | Out-Null
Set-ItemProperty "HKCU:\Software\Classes\$prog\shell\open\command" -Name "(default)" -Value $openCmd

# ② StartMenuInternet：浏览器客户端登记
$smi = "HKCU:\Software\Clients\StartMenuInternet\$app"
New-Item -Path "$smi\shell\open\command" -Force | Out-Null
Set-ItemProperty $smi -Name "(default)" -Value $display
Set-ItemProperty "$smi\shell\open\command" -Name "(default)" -Value $appCmd

# ③ Capabilities：声明能处理的协议 / 文件类型 / MIME
$cap = "$smi\Capabilities"
New-Item -Path "$cap\URLAssociations" -Force | Out-Null
New-Item -Path "$cap\FileAssociations" -Force | Out-Null
New-Item -Path "$cap\MIMEAssociations" -Force | Out-Null
Set-ItemProperty $cap -Name "ApplicationName" -Value $display
Set-ItemProperty $cap -Name "ApplicationDescription" -Value "Portable browser"
Set-ItemProperty "$cap\URLAssociations" -Name "http"  -Value $prog
Set-ItemProperty "$cap\URLAssociations" -Name "https" -Value $prog
foreach ($ext in @('.htm','.html','.shtml','.xhtml','.webp')) {
    Set-ItemProperty "$cap\FileAssociations" -Name $ext -Value $prog
}
Set-ItemProperty "$cap\MIMEAssociations" -Name "text/html" -Value $prog
Set-ItemProperty "$cap\MIMEAssociations" -Name "application/xhtml+xml" -Value $prog
Set-ItemProperty $cap -Name "StartMenuInternet" -Value $app

# ④ RegisteredApplications：登记到"默认应用"列表
Set-ItemProperty "HKCU:\Software\RegisteredApplications" -Name $app -Value "Software\Clients\StartMenuInternet\$app\Capabilities"

Write-Output "注册完成：$display"
```

> **要点说明**
> - `--user-data-dir="{1}"` 必须指向便携版自己的 Data 目录，否则点击链接会启动到系统自带浏览器的数据目录。
> - `--single-argument %1` 保证带空格或特殊字符的 URL 能作为单个参数完整传入 Chromium，避免被拆解。
> - 全部写 `HKCU`，重装系统后不会保留（见第八节）。

### 3.3 修改前先备份

改动注册表前，建议先把当前相关状态存一份文本备份（本环境 `reg.exe` 被安全策略拦截，改用 PowerShell 读值）：

```powershell
$bk = "D:\MyApp\Browser\Edge\_regbackup_$(Get-Date -f yyyyMMdd_HHmmss)"
New-Item -ItemType Directory -Path $bk -Force | Out-Null
$lines = @()
foreach ($proto in @('http','https')) {
    $v = Get-ItemProperty "HKCU:\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\$proto\UserChoice"
    $lines += "$proto UserChoice ProgId=$($v.ProgId) Hash=$($v.Hash)"
}
$lines | Out-File "$bk\state_before.txt" -Encoding utf8
```

本次备份位置：`D:\MyApp\Browser\Edge\_regbackup_20261121_181743\state_before.txt`

## 四、阶段二：在系统设置中点选

注册完成后，便携浏览器会出现在系统"默认应用"列表里，但还**不是**默认。需要你手动点选，让 Windows 计算并写入 Hash。

1. 打开默认应用设置（任选其一）：
   - 按 `Win + R`，输入 `ms-settings:defaultapps` 回车；
   - 或进入 **设置 → 应用 → 默认应用**。

2. 找到 **Web 浏览器**（或搜索"默认浏览器"），在列表中选择刚才注册的显示名，本例为 **Microsoft Edge (Portable)**。

3. 向下滚动，把 **.html** 和 **.htm** 也设为同一个显示名——这样双击本地网页文件也会走便携版。

4. 点选后无需重启，立即生效。

> 此步骤**无法由脚本代劳**：Hash 必须由 Windows 在用户交互时计算，脚本强行写入会被还原。

## 五、验证

### 5.1 检查 UserChoice 是否已切换

```powershell
foreach ($proto in @('http','https')) {
    $v = Get-ItemProperty "HKCU:\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\$proto\UserChoice"
    "$proto -> ProgId=$($v.ProgId)"
}
```

- 若显示 `EdgePortableHTML`（即自定义的 ProgID），说明设置成功。
- 若仍是 `MSEdgeHTM` 等系统值，说明阶段二没点选成功，回到第四节重试。

### 5.2 检查 .html 文件关联

```powershell
(Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\.html\UserChoice").ProgId
```

### 5.3 实际功能验证

- 从其他程序（如聊天软件、邮件）点击一个 `https://` 链接，看是否由便携浏览器打开；
- 双击一个本地 `.html` 文件，确认同样由便携浏览器打开；
- 在便携浏览器地址栏输入 `edge://version`（Chrome 为 `chrome://version`），确认命令行含 `--user-data-dir` 且指向便携版 Data 目录。

## 六、使用工具完成（推荐）

为避免每次手敲注册表命令，已封装为 GUI 工具，位于：

```
workspace\DefaultBrowserTool\
├── 启动_默认浏览器设置.bat     # 双击启动器
└── SetDefaultBrowser.ps1       # GUI 主程序
```

工具沿用现有浏览器迁移工具的 WinForms 风格，同时支持 Edge / Chrome 两个绿色版（下拉框切换，路径自动探测且可手动修改）。四个按钮对应完整流程：

| 按钮 | 功能 |
|---|---|
| ① 注册为可选浏览器 | 写入上述 HKCU 四类注册表项 |
| ② 打开默认应用设置 | 直接拉起 `ms-settings:defaultapps` |
| ③ 检查当前默认 | 读取 UserChoice 并翻译成中文标签，校验是否已生效 |
| ④ 撤销注册 | 移除注册项（若当前默认仍是本浏览器会二次确认） |

使用顺序：**① → ②（在设置中点选）→ ③**。工具界面顶部已注明"不改写 UserChoice"的设计约束。

## 七、撤销 / 恢复系统默认

如需恢复，两种途径：

1. **临时切回**：直接在"设置 → 默认应用 → Web 浏览器"里选回系统 Edge/Chrome 即可，无需删注册项。
2. **彻底移除注册**（工具按钮④，或手动删除以下键）：

```
HKCU\Software\Classes\EdgePortableHTML
HKCU\Software\Clients\StartMenuInternet\EdgePortable
HKCU\Software\RegisteredApplications 中的 EdgePortable 值
```

> 删除前请先在系统设置里把默认浏览器切回其他浏览器，否则删除后默认关联会短暂失效。

---

## 八、重装系统后复用

这些注册项写在 `HKCU`，**不会随便携浏览器目录一起拷贝保留**。重装系统后需要重新执行第三节的注册脚本（或工具的按钮①），再在系统设置里点选一次。

便携版中的书签、历史、扩展等数据保存在 Data 目录，可随目录拷贝保留；默认浏览器设置则需按本文档重新走一遍。

## 九、注意事项与常见问题

| 问题 | 说明 |
|---|---|
| 脚本改 ProgId 后又被还原 | 正常的哈希保护机制。必须走"注册 → 用户点选"路径，不要试图绕过。 |
| 设置列表里找不到便携浏览器 | 阶段一的四类注册项没写全，尤其检查 `RegisteredApplications` 和 `Capabilities`。 |
| 点击链接启动了系统浏览器而非便携版 | 检查 ProgID 的 `open\command` 是否带了正确的 `--user-data-dir` 和 `--single-argument %1`。 |
| 便携版路径变更后链接失效 | 移动/重命名便携浏览器目录后，需更新 ProgID 和 StartMenuInternet 里的命令行路径，再重新点选。 |
| 本环境的工具限制 | `reg.exe`、COM 实例化、`Add-Type -TypeDefinition` 均被安全策略拦截，脚本改用 PowerShell 原生注册表 cmdlet；`Start-Process` 需先清除大小写重复的代理变量，否则报错。 |
| 任务栏图标"打开文件所在位置"指向旧路径 | 与默认浏览器无关，属于跳转列表/隐式快捷方式缓存残留，需单独清理 `ImplicitAppShortcuts` 下的失效 `.lnk`。 |
